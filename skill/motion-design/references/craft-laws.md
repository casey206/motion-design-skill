# 動態設計的物理與時間

業餘與專業的差別在這一頁。每個動作的長度、緩動、過衝、停留都要是**決定過的數值**。

寫 prompt 時這些數值要換成模型讀得懂的自然語言（見最後一節「翻譯成 prompt」），但你心裡要先有數。

---

## §1 緩動（Easing）

Bézier 曲線的 x 軸是時間、y 軸是進度。曲線往**左上凸＝ease out**（快進慢收），往**右下凸＝ease in**（慢起快出）。y 跑出 0–1 範圍＝**過衝或預備動作**。

### 四條產業標準曲線

| 用途 | cubic-bezier | 手感 |
|---|---|---|
| 通用（全程可見的移動） | `0.4, 0, 0.2, 1` | 快速加速、緩慢減速。**沒想法時用這條** |
| 進場（元素從畫面外進來） | `0, 0, 0.2, 1` | 以全速進入，緩慢煞停 |
| 出場（元素離開畫面） | `0.4, 0, 1, 1` | 加速離場，不減速 |
| 可能隨時回來的出場 | `0.4, 0, 0.6, 1` | 兩端都收，較銳利 |

**鐵則：進場比出場慢。** 進場 ~280ms 配出場 ~200ms。反過來會讓整支片顯得急躁。

**線性只有兩個合法用途**：等速旋轉（齒輪、唱盤）、等速捲動（清單、跑馬燈）。其餘一律禁用，線性是「業餘」的最大單一特徵。

### 時長（duration）

| 情境 | 時長 |
|---|---|
| 桌機介面級的小動作 | 150–200ms |
| 手機介面標準轉場 | 300ms |
| 元素進場 | 225ms |
| 元素離場 | 195ms |
| 大型／全螢幕轉場 | 375ms |
| **上限** | **400ms**，超過就會被讀成「卡」 |

**時長隨距離與尺寸縮放**：移動距離或縮放幅度越大，時長越長。同一份設計裡，一個從畫面外飛進中央的卡片不能跟一個原地彈一下的 chip 用同一個時長。

### 動態設計（非介面）的時間尺度

motion graphics 的節奏比介面慢一級：

| 單位 | 長度 | 30fps 的幀數 |
|---|---|---|
| 節拍（beat，一個訊息單位） | 1.5–2.0 秒 | 45–60 幀 |
| 單一元素的移動 | 270–470ms | **8–14 幀** |
| 撞擊／落地 | 67–133ms | **2–4 幀** |
| 眨眼（角色） | — | 8–12 幀 |
| 轉頭（角色） | — | 10–16 幀 |
| 落定後的停留（有字） | ≥ 500ms | ≥ 15 幀 |
| 定版凍結 | 800–1000ms | 24–30 幀 |

**時間分配勝過幀數**：四個間距安排得好的幀，比十二個等距的幀好看。不要用「加幀」解決不順，要用「重新分配間距」。

## §2 過衝與沉降（Overshoot & Settle）

過衝賣的是彈性與意圖：快速停止後讓質量越過目標一點點，再用越來越小的擺動收回最終位置。

| 品牌調性 | 過衝幅度 | 擺動次數 |
|---|---|---|
| 企業／科技／精品（clean） | **3–8%** | 1 次（過衝→回位，結束） |
| 一般商業 | 8–12% | 1 次 ＋ 一個很小的反向 |
| 玩樂／兒童／食品 | 12–20% | 1 次 ＋ 1 次小反向 |

**擺動超過兩次＝玩具感。** 這是「有點廉價」最常見的單一原因。

**沉降要完整**：彈簧要真的停下來，不要在還在抖的時候切鏡。切在抖動中會讓觀眾覺得沒收好。

## §3 預備動作（Anticipation）

快動作前給 **2–4 幀**的反向小移動。物件要往右飛，先往左縮一點。

沒有預備＝「不夠有力」。這是第二常見的「力道不夠」原因（第一是落地沒壓縮）。

預備的幅度與主動作成比例：飛得越遠，預備越大，但預備的**時間**永遠很短（2–4 幀），長預備會變成「猶豫」。

## §4 重量（Weight）

三個數值必須互相同意，否則會讀成假的：

| | 重物 | 輕物 |
|---|---|---|
| 起停幀數 | 多（12–18 幀） | 少（6–10 幀） |
| 過衝 | 小（0–5%） | 大（10–20%） |
| 壓縮（squash） | 小（0–5%） | 大（10–20%） |
| 落地音 | 低頻、長尾 | 高頻、短促 |

一個混凝土板塊用 20% 過衝，或一顆氣球用 12 幀煞停，都會立刻讀成 CG 感。

**壓縮上限 20%**。超過就進入卡通領域，只有刻意的 2D 卡通風格才用。

## §5 錯位（Stagger）

多個元素依序進場，每個延遲 **30–60ms**（30fps 下是 1–2 幀）。

| 元素 | 建議 stagger |
|---|---|
| 標題逐字 | 30–40ms |
| 標題逐詞 | 40–60ms |
| chip／標籤群 | 60ms |
| 卡片群 | 80–120ms |
| 清單項目 | 50–80ms |

**一次只讓一個元素動**是動態設計最省力的高級感來源。全部同時進場是模板感的第一名。

超過 8 個元素的 stagger 會拖太長，改成分組（先 3 個、再 3 個、再 2 個）。

## §6 smear frame（速度線）

2D 快動作的味道來源。做法是在關鍵姿勢之間放 **1–2 幀**變形的過渡幀。

三種型態：
- **拉伸 smear**：物件沿運動方向被拉長
- **重影 smear**：物件被複製成 3–5 個半透明殘影
- **簡化 smear**：物件被簡化成一條色帶或形狀

規則：**只放在移動最快的那一瞬間，絕不連續使用**。連續 smear 會讓整段變糊；太保守則看不出速度。

smear 要跟壓縮、預備、動態模糊一起用才成立，單獨用會像出錯。

## §7 動態模糊與快門

- **180° 快門角度**是產業預設：模糊跨越半個幀間隔。動態圖形與實拍要合板時一定用這個值。
- 快門角度越大模糊越多：360° 跨整幀（很糊），90° 只跨四分之一幀（銳利緊實）。
- **模糊只加在移動的圖層上，背景永不模糊。** 這是 2D 動態設計最容易被抓到的破綴。
- 24fps ＋ 180° ＝ 電影感，但快速橫移會抖；30fps ＋ 180° 是動態圖形的安全值。
- 快速移動有模糊、落定瞬間必須**銳利**。「進場模糊、落地銳利」是專業感的公式。

## §8 文字的可讀性

| 規則 | 數值 |
|---|---|
| 落定後停留 | **≥ 0.5 秒**（讀不完就等於沒放） |
| 畫面文字長度 | 英文 4–7 字、中文 6–10 字（滑動情境下的上限） |
| 字級描述 | 一律用**畫面高度百分比**，不用 px |
| 標題字高 | 約畫面高度 7% |
| 巨大標題 | 約 12% |
| 小標／chip | 約 2.5% |
| 一行標題的強調字 | **只能一個**（整行上色等於沒有強調） |

**字越長越多，動態就要越簡單。** 一句長句配複雜動態＝沒人讀得完。逐字瀑布式進場只適合 1–3 個字的短詞。

落定後的文字必須**鎖在螢幕空間**（screen-locked）：像素級穩定、不抖、不飄、邊緣銳利，即使背後的畫面在動。

## §9 12 動畫原則在動態設計裡的排序

原則有 12 個，但動態設計真正吃重的只有四個。**把這四個內化，作品立刻專業**：

1. **緩動（Slow In / Slow Out）** — §1
2. **時間分配（Timing）** — §1
3. **跟隨與重疊（Follow Through / Overlapping Action）** — 主體停了，附屬物（緞帶、陰影、文字下標）晚 2–4 幀才停
4. **預備動作（Anticipation）** — §3

其次有用的：壓縮與伸展（§4）、弧線運動（直線移動讀起來很機械，給軌跡一點弧度）、次要動作（主動作之外的一個小動作）、舞台呈現（一次只有一個最強焦點）。

角色動畫專屬的（實體感、誇張、直線推進 vs 姿勢對位）在動態設計裡基本用不到，除了 2D 角色 explainer。

## §10 翻譯成 prompt

模型不吃 cubic-bezier。把數值翻成**物理的、可觀察的**描述：

| 你的決定 | prompt 寫法 |
|---|---|
| ease-out, 300ms, 5% 過衝, 1 次沉降 | `enters with one confident ease — fast attack, long soft settle, a single small overshoot, no bounce` |
| ease-in 出場 | `exits ease-in and accelerates off frame` |
| 線性禁用 | `nothing eases linearly — everything overshoots and settles` |
| 2–4 幀預備 | `a tiny counter-move before the launch, then the fast travel` |
| 落地 1 幀壓縮 | `one-frame squash and a quick damped rebound on every landing` |
| stagger 40ms | `staggered 40ms, word by word` |
| 停留 0.5 秒 | `holds frozen and pixel-stable for a beat before dissolving` |
| 180° 快門，只模糊移動層 | `directional motion blur on the moving layer only, the background never blurs` |
| 進場模糊落地銳利 | `motion blurred on entry and sharp on landing` |
| 跟隨動作 | `the ribbon keeps swinging for a beat after the medal has settled` |
| 重量對齊 | `concrete grows with visible mass, lands heavy with almost no rebound` |
| 過衝上限 | `no bounce and no overshoot`（clean 風格）／`squash-stretch up to 20%`（玩樂風格） |

**一律用正向敘述描述動態本身**（要什麼），禁用清單集中放在 RENDER 區塊處理視覺雜訊（顆粒、光斑、浮水印）。
