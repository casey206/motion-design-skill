Layout rules

  1. 一行標題只有一個強調字上 ACCENT，其餘一律 INK 或 PAPER。
  2. 圖形元素只用兩色：ACCENT ＋ PAPER。INK 只出現在 PILL 內的字與 BADGE 內的勾。
  3. 9:16 安全區：上 12%、下 15% 不放關鍵資訊；wordmark 與 identity anchor 落在中央 73% 高度內。
  4. 字級一律以畫面高度百分比描述，不給 px。
  5. 一次只有一個元件在動；落定後 screen-locked，不抖不飄。
  6. 百分比 TRACK 的填色長度 ＝ 標示的百分比，第一幀就印好，永不動畫。
  7. 無漸層、無描邊（OUTLINE TYPE 除外）、無陰影、無光暈、無顆粒。
